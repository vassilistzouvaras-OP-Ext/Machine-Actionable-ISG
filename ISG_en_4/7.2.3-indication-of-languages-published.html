7.2.3. Indication of languages published

Different formulas are used when listing language versions of publications in catalogues.

When the language versions of a publication are listed (e.g. in the publication catalogues), it is advisable to use the following formulas (in accordance with the rule presented in Section 7.2.1).

Combination Context
BG/ES/CS/DA/DE/ET/EL/EN/FR/GA/HR/IT/LV/LT/HU/MT/NL/PL/PT/RO/SK/SL/ FI/SV
or any part combination		 The text is published in each language mentioned in the same volume.
BG, ES, CS, DA, DE, ET, EL, EN, FR, GA, HR, IT, LV, LT, HU, MT, NL, PL, PT, RO, SK, SL, FI, SV
or any part combination		 The text is published in each language mentioned in individual volumes by language.
BG-ES-CS-DA-DE-ET-EL-EN-FR-GA-HR-IT-LV-LT-HU-MT-NL-PL-PT-RO-SK-SL-FI-SV
or any part combination		 Different texts are published in some of the languages mentioned, in the same volume.
NB:

ISO codes for languages are written in lower-case letters; nevertheless, they are also written in capital letters for typographical presentation reasons.
