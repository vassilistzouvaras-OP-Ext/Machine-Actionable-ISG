3.4. Order of citation

The Treaties, authors, countries, languages and currencies are cited in a specific order and using given forms.

The Treaties, authors, countries, languages and currencies are cited in a specific order and using given forms.

  • 3.4.1. Order of the Treaties
    The order in which Treaties are cited (particularly in the citations) depends on when the text was published; in some cases certain abbreviated forms can be used.
  • 3.4.2. Order by author
    Under the different headings and subheadings of the Official Journal (L and C series), authors appear in a defined order.
  • 3.4.3. Countries
    Names and abbreviations of languages and the order in which languages and language versions appear are defined to be used in the same way in all EU texts.
  • 3.4.4. Languages and multilingual texts
    Names and abbreviations of languages and the order in which languages and language versions appear are defined to be used in the same way in all EU texts.
  • 3.4.5. Currencies
    Names and abbreviations of currencies and the order in which they appear are defined to be used in the same way in all EU texts.
