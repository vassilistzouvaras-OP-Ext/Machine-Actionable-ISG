7.2. Languages

Different rules apply when listing language versions and when listing languages.

Different rules apply when listing language versions and when listing languages in text.

  • 7.2.1. Order of language versions and ISO codes (multilingual texts)
    The language versions should appear in the Roman alphabetical order of the formal titles in their original written forms.
  • 7.2.2. Listing languages in text (unilingual texts)
    In text, languages are always listed in alphabetical order in the language of publication, and therefor varies according to the linguistic version.
  • 7.2.3. Indication of languages published
    Different formulas are used when listing language versions of publications in catalogues.
  • 7.2.4. Rules governing the languages of the institutions
    The Council determines the rules that govern the languages of the institutions; there are currently 24 official and working languages.
